# Web Application Programming

This repository contains the laboratory exercises developed for the Web Application Programming course.

It is intended to collect and organize all the labs completed by the students during the course.

## Repository Structure

Laboratory exercises are stored in the `labs` directory.

## Student Branches

Each student has a personal branch named after their first and last name.

Students should use their own branch to upload and update their laboratory exercises.

For example:

- `francesco-ciriaco`
- `marco-bidoli`

This allows each student to work independently while keeping all the course laboratory exercises within the same repository.
